# CSV/JSON の列とレコードの扱い

`/csv-json` の JSON → CSV は、すべてのオブジェクトのキーを走査して列を作ります。列はキーが初めて現れた順（各オブジェクト内では JavaScript の `Object.keys` 順）に並び、欠けたキーは空欄になります。

例えば `[{"name":"田中"},{"email":"taro@example.com"}]` は、先頭行だけに合わせて email を捨てず、name と email の2列を出力します。空オブジェクトの行も、他の行にキーがあれば空のレコードとして残します。継承プロパティは値として扱いません。

## エラーと回復

- CSV → JSON（ヘッダーあり）では、同じ名前のヘッダーとヘッダーより多い列を拒否します。重複名の列番号や、問題のレコード番号・列数を示します。ヘッダー名・数を修正するか、ヘッダーなしに切り替えると、列を配列として保持できます
- 少ない列は従来どおり空文字で補います。ヘッダーなしでは行ごとの列数が異なっても保持します
- JSON のレコードはすべてオブジェクト、またはすべて配列に統一します。混在した行・null・プリミティブは変換せず、問題のレコード番号を表示します
- 空の配列の行と、全行にキーがないオブジェクト配列は CSV に表せないため拒否します。1列の空値は引用符付きの空フィールドとして保持します
- エラー時には出力をクリアし、コピーを無効にします。入力は残るので、修正して再変換できます

レコード番号は空の物理行を除いた論理レコードの1始まりです。CSV ヘッダーも1レコードと数え、引用符内の改行は同じレコードに含めます。

## 既存の変換規則

カンマ・タブ・セミコロン、引用符内の改行、前後の空白、BOM の処理は維持します。JSON の null と欠けたキーは空欄になり、CSV → JSON の値は文字列になります。数値は従来の JavaScript JSON 解析を使うため、大きな整数や精密な小数を正確に扱う必要がある場合は文字列として入力してください。ネストしたオブジェクト・配列は JSON テキストのフィールドとして出力します。CSV の列・行の保持は、JSON の型や null・欠損の区別の可逆性を保証するものではありません。

変換はブラウザー内で完結します。API、認証、外部送信、保存形式の移行は追加しません。
