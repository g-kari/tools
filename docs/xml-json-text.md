# XML/JSON のテキスト変換

XML → JSON は、各要素の直接のテキストノードと CDATA を結合して変換します。
子要素と混在する直接テキストは、子要素を表すキーと併存する `#text` に格納します。
コメントや処理命令、子要素の内部テキストは親の `#text` に含めません。

JSON → XML は、子要素がある場合も `#text` を出力します。値が空文字列、0、false、null でも省略しません。
混在テキストを持つ要素では整形用の空白を追加せず、子要素をインラインで出力します。
混在テキストを持つ要素の子孫もインラインで出力します。この部分木の外にあり、`#text` がない要素では従来のインデント整形を維持します。

## 既存の表現上の制約

- XML の直接テキストは結合後に前後の空白を除去します。空白のみの内容は空文字列になり、子要素がある場合は `#text` を追加しません。
- CDATA は通常の文字列になります。CDATA 境界を再現しません。
- 同じ名前の子要素はグループ化されます。異なる名前の子要素の元の交互順序や、子要素間のテキストの位置は再現しません。
- JSON → XML の `#text` は子要素の前にまとめて出力します。
- コメント・処理命令・DOCTYPE はこの JSON 表現の対象外です。

この変換は、XML 文書の完全な無損失往復を提供するものではありません。
